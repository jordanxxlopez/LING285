2|**A single neuron takes a list of inputs and gives back one weighted sum.** It multiplies each input by its weight and adds the products, so an inner product turns the input vector into one response. >> A neural network combines many such operations through its layers and returns a decision vector, with a response for each possible answer. || **A large language model takes a sequence of vectors and predicts what comes next.** Each layer transforms the representations produced by the preceding layer, until the output gives the probabilities of the possible next tokens. >> A likely continuation receives a stronger predicted response, so the final vector expresses a decision about the sequence. || **An agentic system connects whole language models into a graph.** Different models develop the outline, write the draft, criticize it, revise it and produce the final answer. >> The critic and reviser form a loop, allowing a changed draft to be evaluated again. The agents communicate in English and can work in other human languages and computer languages. || **Inference uses learned weights to process an input, while learning changes those weights.** Inner products supply the weighted combinations used in inference, and stochastic gradient descent adjusts the weights using the backward calculation organized through dynamic programming.
3|**Predicting the next word requires useful representations of the sequence, so a language model develops those representations through many layers.** Each layer receives the vectors produced by the layer before it and changes them into information that can help with the prediction. >> A representation is the information about an input item carried in its vector. || **Several heads work in parallel inside each layer.** Each acts as a different expert, contributing information that the layer combines with the contributions of the other heads. The result is a new set of representations that brings those contributions together. >> The experts here are processing components within the model. A head contributes to one layer, while an agentic graph connects whole language models to work on a task. || **The following layer repeats the process using the representations it receives.** Its heads again work in parallel, and their contributions are combined before the vectors continue onward. >> The heads provide different contributions within a stage, while the layers develop the representations through successive stages. The final prediction depends on both kinds of organization.
4|**A dynamical system repeatedly turns its current state into a new state by applying a rule.** An oscillator’s state contains position and velocity, and the two quantities take turns changing. Position is updated using the old velocity, and velocity is then updated using the new position. >> Feeding the updated state back through the rule produces an oscillating trajectory from the starting state. || **Jordan’s recurrent network uses feedback to carry recent output into the next moment.** Plan and state units feed the hidden layer, and the output is copied back into the state units. Their self-connections keep a fading trace of the earlier state. >> The same weights are reused as time advances, so each new output depends on the plan and on the history carried by the state units. || **An LLM develops its vectors through successive layers, so depth plays the role of time in this comparison.** One layer transforms the vectors, and the next layer uses those transformed vectors as its own input. >> Following a single value through the layers gives a changing trajectory. The trajectory develops step by step, but its curve is not the oscillator’s cosine. || **The oscillator and Jordan network reuse the same rule at each time step, while the LLM has a separate set of weights at each layer.** The shared principle is that each new state depends on the state produced before it, with network depth supplying the sequence of transformations for the LLM. || A changing quantity can follow a different path from another quantity over the same period. The stock-return sequences rise and fall along separate paths. Each path records a sequence of values, just as following a value through successive transformations gives its trajectory.
5|**A language model takes a sequence of vectors and predicts the next item.** A vector is a list of numbers, so the same input format can represent different kinds of material. >> The prediction task stays the same even when the sequence comes from a different source. || **The vectors can represent words in a sentence.** In the cat that the dog chased ran up the old tree and sat on the blank, the task is to predict the missing next word. >> The prediction uses the sentence so far, including the fact that the cat is the one that sat. || **The vectors can represent pieces of sound or a picture.** A spectrogram is divided into consecutive frames, and the model predicts the next frame of sound. A picture is divided into patches read row by row, and the task is to predict the missing bottom-right patch. >> The input represents an unfolding sound in one case and an ordered set of picture pieces in the other. || **The vectors can also represent amino acids in a protein.** The insulin B-chain example gives a sequence of amino acids and leaves the following residue to be predicted. >> The amino acid at the next position is Y. || **Words, sounds, picture patches and amino acids reach the model as sequences of vectors.** The model uses the preceding vectors to predict the following one, even though the original materials are different.
6|English allows only **certain sequences of sounds** in its words, and knowing which sequences are allowed is called **phonotactic knowledge**. **A simple syllable in English can have a consonant, then a vowel, then a consonant**, as in Don, mat, sit, cup, dog and fish. >> The pattern is about sounds, not letters, so the silent e in shave, kite and rope does not count, and two letters can spell one consonant sound, as in ship, chin and bath. || Syllables can also have **clusters**, which are groups of consonants together. A cluster before the vowel is called an **onset**, as in split, flat and black, and a cluster after the vowel is called a **coda**, as in desk, help and lamp. >> Each real word has an impossible twin marked with a star, and many twins use the same letters in the other order, such as flat and lfat, help and hepl, and lamp and lapm, so the order of the sounds matters. >> **The order of consonants mirrors itself around the vowel.** In flat the l sits right next to the vowel with the f farther out, and in help the l again sits next to the vowel, now on the other side, with the p farther out. Each impossible twin puts the wrong consonant against the vowel. || **A long word is a chain of syllables**, such as ba-na-na, At-lan-tic and ath-lete. The sounds t and l are fine across a syllable break, but tl cannot start a syllable, which is why Atlantic is a word but tlantic is impossible. >> The sound ng can end a syllable, as in ring, but it can never start one. >> So whether a sequence of sounds is allowed depends on where the syllable breaks fall.
7|**Phonotactic knowledge can be revealed through GPT learning.** Each item is the start of an English word, and the task is to guess the next letter. People agree on their guesses quickly, and how much they agree changes from item to item. || **Almost anything can follow once a vowel has come.** After ra, likely letters include t, n, r and l, and many others are possible too, because the onset is over once the vowel arrives. >> **At the start of a word, the choices narrow sharply** to exactly what an English onset allows. After sp the next letter is l, r or a vowel and never n, and after k it is a vowel or n, as in knee. >> After b and f the next letter is r, l or a vowel, after sh it is a vowel or r, as in shrimp, and after skr or after m at the start of a word only a vowel can come. >> After bram, the letter b is almost forced, as in bramble, though a new syllable could also start there. || **Guessing the next letter is the same as predicting the sixteenth item**, which is the same game of predicting the next token that a large language model plays. A GPT trained only on this game learns English sounds and spelling, because its predictions can only get good by matching the patterns of English syllables. >> Its prediction is a probability distribution over the next letter, and the shape of that distribution carries the knowledge. >> After ra the distribution is broad, spread over many letters, while after skr it is sharply peaked on a few vowels, because English allows nothing else there. >> So the more the letters so far restrict what can come next, the more the probability piles onto a few letters.

9|**An LLM learns by trying to guess a word that has been hidden from it.** In the sentence “The chef cracks the,” the model reads every word before the gap and then has to say which word fills the gap. >> Each earlier word gives a clue about the hidden word. These clue relationships between the parts of a sequence are called **interdependencies**. || **The model does not know the answer, so it spreads its bets across several words.** It gives the largest bet to “egg,” a smaller bet to “nut” and the smallest bet to “code.” >> A bet is the probability the model gives to one word. The earlier words are what make “egg” more likely than the other two. || **Learning is the nudging of the weights so that these guesses get better.** After the true word is revealed, the weights change a little, so the right word gets a bigger bet the next time. >> The same idea holds when the signal contains sounds and images as well as words. The model still guesses a hidden piece from the pieces around it.
10|**Text is the easy case because it is already a row of separate pieces.** The sentence “Now crack the egg” divides into its words, and each word can become one vector. >> A row of vectors is the only form an LLM can read. || **Speech and images do not arrive as rows of pieces.** Speech is air pressure that keeps changing in time, and an image is a grid of light. >> Neither of them contains any words, so neither can be given to the model as it is. || **The first job is therefore to convert speech and images into rows of vectors.** Once that is done, all of the forms look the same to the model. >> The model can then read words, sounds and images together in one sequence.
11|**Speech is converted by slicing it into short pieces of time called frames.** Each frame lasts only about 20 milliseconds, and the frames follow one another in time. >> The cuts are made at regular times and do not follow the boundaries between words. || **The slices pass through a speech encoder, which gives back one vector for each slice.** A speech encoder is a neural network that was trained on a large amount of audio. >> Slices that hold different sounds come out as vectors that hold different numbers. || **One second of speech becomes 50 vectors, and the vectors stay in time order.** The speech has become a row, just like a sentence. >> The model can now read the sound one vector after another, the way it reads the words of a sentence.
12|**An image is converted by cutting it into small squares called patches.** In the example, an image of an egg in a pan is cut by a grid into 16 patches. >> Each patch is one small piece of the whole image. || **The patches are laid out in a row in reading order, from the top left to the bottom right.** This gives the image a fixed order, so it becomes a sequence like a sentence. >> The patches then pass through a **vision encoder**, which gives back one vector for each patch. || **Real systems cut an image into much smaller patches than the example does.** Their patches are only 14 to 16 pixels wide, so a single image gives hundreds of vectors. >> The example uses a few large patches only to keep the idea simple.
13|**Image patches, speech frames and words can all be placed in one row.** The patches come first, the frames come next and the words come last, with the final word hidden. >> The words that the model can read are “Now,” “crack” and “the.” || **The earlier words still give clues, and the other senses now give clues as well.** A patch that contains an egg helps the model guess the hidden word, and so does the sound of cracking. >> A clue that reaches from one sense to another is called a **cross-modal dependency**. || **The game itself has not changed at all.** The model still guesses the hidden piece from the pieces that it can read. >> The only difference is that some of the clues now come from other senses.
14|**The phrase “three cute puppies” can be given to the model in three forms.** It can be an image of three puppies, the phrase spoken aloud, or the three written words. >> The image is cut into 18 patches, in the same way as the image of the egg. || **The spoken phrase is displayed as a spectrogram, which lays the sound out in time.** Time runs from left to right, a higher position means a higher frequency, and a darker area means more energy. >> Each word occupies its own stretch of time, and each thin column of the spectrogram is one frame. || **The image, the sound and the words are three views of one event.** In training, all three are placed together in one row. >> The model then plays the same game on that row, guessing whichever piece has been hidden.
15|**In the first training example, the hidden piece is the word that follows “three cute.”** The row holds the image first, then the sound, then the words. >> If the model had only the words, many endings would fit, such as “kittens,” “puppies” and “babies.” Its bets would be spread out, with no word far ahead. || **The image and the sound add clues that settle the guess.** The image contains puppies, and the sound contains the spoken word “puppies.” >> With these clues, the bet piles up on “puppies,” and the other two words are left with very small bets. || **When the true word is revealed, the model is graded on how much it bet on that word.** The true word is “puppies,” and the model had placed a large bet on it. >> A large bet on the truth means the error is small. A small error moves the weights only a little.
16|**In the second training example, the hidden piece is one frame of the sound.** The row is reordered so that the image comes first, then the words, then the sound, which is like teaching the model to speak a sentence it was given. >> The sound is predicted one frame at a time from left to right, so the frames after the hidden one have not been heard yet. || **The strongest clue comes from the frames just before the hidden one.** The speaker’s voice and the **formants** (frequency regions with strong energy) change smoothly, so recent frames say a lot about the next frame. >> The words say which sound should come next, which here is the vowel in “pup.” The image contains puppies, so it backs up the words, although it is a weaker clue in this case. || **The guess is compared with the true frame one number at a time.** A frame is a column of numbers, and each number is the amount of energy in one frequency band. >> The guess is close but not exact, and the error is how far each guessed number is from the true one. That error nudges the weights.
17|**In the third training example, the hidden piece is one patch of the image.** The row is reordered again so that the words come first, then the sound, then the image, which is like teaching the model to draw what it was told. >> The patches are predicted in reading order, so the patches after the hidden one have not been drawn yet. || **The clues tell the model that a puppy ear belongs in the hidden patch.** The earlier patches give background above and two puppies to the left, so the model has seen what a puppy in this image looks like. >> The word “three” says that one more puppy must appear, and the word “puppies” says to expect dog ears. The sound carries the same words, so it backs up the text. || **The model guesses a blurry puppy ear in the average colour of the first two puppies.** The true patch belongs to a dark puppy, so the biggest error is the colour. >> No clue in the words, the sound or the earlier patches said that the third puppy would be dark. Only systems that also produce images are trained in this way.
18|**Any piece of the row can be the hidden one, and each sense gives a clue for it.** For a hidden word, the words “three cute” call for a plural noun, the sound has just spoken the word, and the image contains puppies. >> For a hidden frame, the words say which sound comes next, the voice and formants carry on, and the image backs up which word is being said. || **For a hidden patch, the clues follow the same pattern.** The word “three” says that one more puppy is coming, the sound gives the same words in heard form, and the fur and background carry on from the earlier patches. >> In every case, one of the three clues comes from the same sense as the hidden piece. || **A clue from the same sense mostly says how the signal continues.** Grammar, smooth formants, and fur and background all carry on from what came before. >> Clues from the other senses mostly say what the thing is, which here is puppies, three of them. Training on all the senses together helps because each sense fills gaps the others leave.
19|**For the model to speak, sound is first compressed into discrete codes.** Each code is a number that stands for a short piece of sound, and it works like a new word added to the vocabulary. >> The model predicts the next code exactly as it predicts the next word, so speaking is the same guessing game again. || **A decoder then changes the predicted codes back into a sound wave.** The model supplies the row of codes, and the decoder supplies the sound that can be heard. >> Speech output therefore uses the same prediction as text output, followed by one extra decoding stage. || **Three things are new when a model is trained on several senses.** The first is a shared currency in which everything becomes vectors in one row, the second is data where the senses appear together, and the third is a schedule that protects what was already learned. >> What stays the same is the learning rule, which is to find the dependencies in the signal. The signal has only become wider.
